## 🎯 About

A clean archive of **50 Level 1 C++ problems**. Every problem has its own folder, the main solution is kept in `Solution-01.cpp`, and alternative approaches are stored separately whenever they exist.

> **Learn → Solve → Compare → Practice → Improve**
